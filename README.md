# โลมานีออน ผู้พิทักษ์สมุทร (Neon Dolphin Survivor)

เกมแนว 2D Horde Survival (Vampire Survivors-like) สร้างด้วย Godot 4.7.2 (Procedural 2D + Procedural SFX)

## เล่นผ่านเว็บ (GitHub Pages)
เปิดเล่นบนเบราว์เซอร์ทั้ง PC และมือถือได้ที่:
`https://kornthitapanno-web.github.io/dolphin-survivor/`

## การควบคุม
- **คีย์บอร์ด**: `WASD` หรือ ปุ่มลูกศร (เดิน 8 ทิศ), `Esc` / `P` (พักเกม)
- **จอยสติ๊ก (Controller)**: ก้านอนาล็อกซ้าย / D-Pad (เดิน), ปุ่ม `A` (ตกลง), ปุ่ม `Start` / `Back` (พักเกม)
- **มือถือ**: แตะลากฝั่งซ้ายของจอเพื่อบังคับทิศทาง และแตะปุ่มบนจอ

## ด่านและระบบในเกม
- **2 ด่าน**: แนวปะการังน้ำตื้น (90 วินาที) และ ห้วงเหวน้ำลึก (120 วินาที)
- **อาวุธอัตโนมัติ 4 ชนิด**: คลื่นโซนาร์, ฟองอากาศจู่โจม, กงจักรน้ำวน, สายฟ้าชีวภาพ
- **ระบบอัปเลเวล & ความสำเร็จ (Achievements)**: สุ่มการ์ดอัปเกรด 3 ใบเมื่อเลเวลอัป พร้อมภารกิจความสำเร็จ 7 รายการ
